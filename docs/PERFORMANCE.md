# Keen 性能测试记录

> 维护人：范显  
> 最后更新：2026-10-13  
> 状态：尚未建立运行时基线

## 目标

| 指标 | 目标 |
| --- | --- |
| 普通文档热打开 | 小于 300ms |
| 文件修改后刷新 | 小于 500ms |
| 空闲 CPU | 尽量接近 0% |
| 普通文档内存 | 尽量控制在 150MB 左右或以下 |

## 必测口径

- Keen 主进程常驻内存。
- WebKit WebContent 进程常驻内存。
- 空闲和滚动时 CPU。
- 冷启动与热启动耗时。
- 普通、超长、表格密集文档打开耗时。
- 外部连续写入后的防抖与刷新耗时。
- 多标签切换耗时和 WebView 数量。

## 当前记录

首次 Release 编译成功，App 启动后未立即崩溃。尚未使用 Instruments、`vmmap`、`ps` 或应用内埋点得到可复现性能数据，因此不声明达到性能目标。
