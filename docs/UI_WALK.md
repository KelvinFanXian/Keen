# Keen UI Walk 记录

> 维护人：范显  
> 最后更新：2026-10-13  
> 基线文档：`UI_WALK_SAMPLE.md`、`UI_MERMAID_SAMPLE.md`

## 本轮结论

已使用真实 Release App 在 1320 × 840 窗口下走查文件树、标签栏、正文、大纲、任务列表、表格和 Mermaid。

## 已修复

- 三栏内容未撑满窗口高度，窗口上下出现大块空白。
- 空状态按钮宽度不足导致“打开文件夹”被截断。
- 空大纲提示过重。
- 任务列表同时出现普通圆点和复选框，文字被挤到下一行。
- Mermaid 被当作普通代码块展示。
- 标签较多时当前标签被右侧大纲边缘截住。
- 文档内相对 Markdown 链接未直接打开目标文档。
- Finder/Open With 反复启动时恢复出多个重叠窗口；调整为唯一主窗口和多标签模型。

## 已验证

- 三栏填满窗口，正文保持最大阅读宽度。
- 文件树、标签和大纲层级清晰。
- 中英文、行内代码、引用、任务列表和表格排版正常。
- Mermaid 在真实 App 的 WKWebView 中生成 SVG，不显示源码；缩放、适应宽度和平移控件可见。
- Mermaid 资源仅在文档包含 `mermaid` fenced block 时载入。
- 本地链接解析覆盖 `.md`、`.markdown`、中文文件名、无扩展名目标、目录 README 和章节锚点。

- 1000+ 标题文档的大纲滚动。
- Mermaid 复杂 ER、Sequence、Class、State 和 Gantt 图。
- 键盘完整操作和 VoiceOver 辅助功能。
