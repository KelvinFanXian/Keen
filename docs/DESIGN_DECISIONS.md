# Keen 设计决策

> 维护人：范显
> 最后更新：2026-10-19

本文件记录稳定的产品取舍。实施新需求时先核对这里；若确实要改变决定，应先写明新决定和原因，再更新界面与测试。历史调整和验收进度另见 `ADJUSTMENTS.md`。

## D-001：只服务一位用户

Keen 是范显自己的 Markdown 阅读器，不以通用编辑器或多主题产品为目标。优先打磨日常阅读路径，避免为了“可配置”增加长期维护负担。

## D-002：始终只读

文档内容由其它工具维护。Keen 可以搜索、导航、复制、刷新和查看附件，但不提供编辑模式，也不修改 Markdown 原文。借鉴 Vim 时仅借用阅读导航键位，不引入普通/插入/命令模式。

## D-003：固定浅色 Swiss 正文

正文仅使用 Marked 3 Swiss 取向的一套排版，并持续优化其标题、表格、代码、图片和留白。界面固定浅色；不再提供 Everforest、Ink、Manuscript、深色或跟随系统的切换入口。保留字号和阅读宽度调节，因为它们直接服务阅读。

## D-004：让内容成为窗口主体

应用内容区只分文件树、正文、大纲三列，不显示底部状态栏。非全屏时中间顶部显示多文件标签，右上角始终显示文件侧栏与大纲两个小图标（按此顺序）；大纲隐藏后，图标留在中间标签栏右端，确保能够重新唤出大纲。全屏时三列内容直接到顶，不显示页面内标签栏；两个图标移到 macOS 系统标题栏，避免空白系统栏，也不压住正文或大纲。操作还可通过菜单栏和快捷键完成。全屏切换用 `⌃⌘F`，工作区文件搜索保留 `⇧⌘F`。

## D-005：导航区与正文有轻微层次

左侧文件导航使用中性浅灰背景、较克制的文字和选中态；正文保持白底。文件树紧接交通灯区域，不设置常驻搜索框；`⇧⌘F` 打开工作区 Markdown 全文搜索，正文命中优先显示，也可用相对路径定位文件。右侧大纲默认明显窄于左侧文件树；左右分隔线都允许拖动调整，分别记住宽度，同时为正文保留最小阅读空间。当前只验收浅色方案。

## D-006：键盘优先但不强迫记忆

常用操作保留明确快捷键，文件树遵循方向键移动、空格打开文件、左右键收展目录。Vim 风格阅读键可关闭，仅在正文阅读区响应；搜索框等输入区域不应被劫持。鼠标操作和菜单仍可完成同一任务。

侧栏与阅读模式优先使用双键组合：`⌘B` 文件侧栏、`⌘L` 大纲、`⌘J` 专注阅读、`⌘K` 切换 Vim 阅读键。避免为了只读操作叠加多个修饰键；系统惯用的 `⌃⌘F` 全屏快捷键保留。

Vim 键位是可选的“焦点内导航层”：正文 WebView 获得焦点且没有输入控件时，沿用 `j/k`、`⌃D/⌃U`、`⌃F/⌃B`、`gg/G`、`gt/gT`、`⌃O/⌃I`、`/`、`n/N` 的原有语义；文件树获得焦点时，用 `j/k` 移动、`h/l` 收展，`Space` 打开。其它输入控件不受影响。不添加编辑模式、写入命令或复杂 Leader 配置。全局菜单快捷键与这一层分离，避免相互抢键。
