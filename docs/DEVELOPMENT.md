## 已实现

- Swift Package 原生 macOS 应用骨架，最低 macOS 15。
- SwiftUI 三栏界面、原生工具栏和设置窗口。
- 文件夹懒加载和 Markdown 文件过滤。
- 文件侧栏支持折叠、文件名搜索；已展开目录发生新增、删除或重命名时自动失效缓存并刷新。
- VS Code 式预览标签：单击预览、双击固定，并支持关闭其它与关闭右侧。
- `swift-markdown` AST 解析、HTML 转义和 WKWebView 渲染。
- AST 标题 source range 生成大纲和源码行号。
- 大纲点击跳转、正文滚动章节同步、章节位置复制。
- Mermaid 11.17.2 本地按需加载、严格安全模式、适应宽度、缩放、平移和错误降级。
- 文档内相对 Markdown 链接、中文文件名、无扩展名链接、目录 README 和章节锚点跳转。
- 文档内链接导航保留前进/后退历史，支持工具栏按钮及 `⌘[`、`⌘]`。
- `⌘F` 打开页内搜索并自动聚焦输入框；搜索栏已打开时再次按下也会取回焦点。输入实时高亮正文中的全部匹配，并可循环跳转上一处或下一处；`Esc` 关闭搜索。
- 切换标签、点击文档链接或使用前进/后退后，文件树会自动展开并滚动选中当前文档，保持阅读页与项目位置同步。
- 右侧大纲不限制最大宽度，可拖动分隔线按长标题内容自由调整，仅保留防止侧栏消失的最小宽度。
- `⌘1`～`⌘9` 可直接切换对应标签；`⌘E` 打开当前工作区最近 10 个文件面板，支持单击打开或键盘选择后回车打开。记录按工作区根目录隔离并跨重启保留，工作区外文件不会污染当前目录。
- 工作区切换时先保存当前目录的标签集合与选中标签，再清空界面并恢复目标目录自己的会话；左下角工作区菜单提供打开目录、Finder 定位、刷新及最近目录切换。
- 文件在外部被删除、移动或重命名导致旧路径失效时，文件与目录监听会清理无效标签、更新工作区会话，并切换到相邻的有效标签，不再停留在“无法读取文档”页面。
- 最近目录支持悬停固定/取消固定和移除；固定目录稳定置顶且不会被数量上限淘汰，状态跨重启保存。工作区弹层采用紧凑行高、轻量悬停层级和明确的当前目录标记。
- 工作区弹层不显示多余的关闭按钮，沿用系统 Popover 点击外部自动关闭的行为；固定和移除图标不进入键盘焦点链，避免点击后残留系统蓝色焦点框。
- 工作区弹层移除独立标题栏，使用 292pt 紧凑宽度、较小分组间距及 28～31pt 行高；目录操作复用行尾空间，仅在悬停或已固定时出现。
- UI Walk 样本文档、三栏高度自适应、精简空状态和阅读排版细节。
- Everforest Light、Swiss、Ink、Manuscript 四套样式；正文保持舒适行宽，宽表格按阅读视口展开。
- Everforest Light 使用宽幅统一内容轴、奶油色背景、蓝灰正文、绿色链接和琥珀色行内代码。
- 默认回归 Marked 3 Swiss 取向；Mermaid 保持自然尺寸并左对齐，仅在超出视口时缩小。
- Swiss 按 Marked 3 实际运行效果使用宽幅阅读区；问题清单表按表头识别并稳定正式编号、问题、证据与状态列宽。
- 表格按表头识别修改历史语义，专用列宽不再误伤普通五列表格；切换文档默认回到顶部。
- 重启时恢复上次预览文档，避免只恢复标签而正文为空。
- Marked 3 风格紧凑表格：常见五列表格列宽优化、纯色表体和专注阅读模式。
- 文件与目录事件监听、防抖和自动刷新；当前文件被删除时自动关闭失效标签。
- 本地 `.app` 打包、ad-hoc/开发证书签名和签名校验。
- 原创 Keen 图标接入资源。

生成提示词摘要：为 Keen 原生 Markdown 阅读器设计 macOS 图标，以折叠文档页和负空间视线表达“专注阅读与清晰”，使用深墨蓝、暖白和少量青色，保持简单几何、轻微纸张层次、清晰轮廓；禁止文字、水印、霓虹、过度渐变和通用书本图标。
